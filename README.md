# IF and Else Operators Assignment

## Project Overview

This project is based on JavaScript IF, ELSE, Comparison, and Logical Operators. It contains different real-world challenges to practice decision-making using conditions.

## Challenges Included

### 1. Student Result & Eligibility

* Check pass or fail status
* Verify attendance
* Check exam eligibility
* Scholarship qualification

### 2. Online Shopping Website

* Minimum order verification
* Wallet balance check
* Order placement validation
* Free delivery eligibility

### 3. Gaming Platform

* Level requirement check
* Coins verification
* Mission unlock eligibility
* VIP content access

### 4. Bank Account Verification

* Daily withdrawal limit check
* Account balance verification
* Withdrawal approval
* Special withdrawal eligibility

### 5. Event Registration System

* Age requirement validation
* Seat availability check
* Registration eligibility
* VIP area access

### 6. Job Application Portal

* Experience verification
* Degree completion check
* Interview eligibility
* Priority consideration

### 7. University Admission

* Test score verification
* Document submission check
* Admission eligibility
* Alternative admission path

## Technologies Used

* JavaScript
* VS Code
* GitHub

## Learning Objectives

* IF and ELSE statements
* Comparison Operators
* Logical Operators (&&, ||)
* Strict Equality (===)
* Strict Inequality (!==)
